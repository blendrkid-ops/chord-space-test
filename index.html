Editing the roll
Drag a note up or down to move it to a new octave. Double-click a note to clear a chord's hand-placed voicing. Click a chord's roman numeral or name above its column to hear it and open full control over which notes it uses.
What these numbers mean
The exact optimal voice leading between each pair of chords — the least motion an ideal bijective assignment achieves, in pitch-class space (each voice takes the shorter path around the octave), with the smaller chord doubling a tone when sizes differ.
The toggle above
Switches which optimum is sought: least total motion (L1, all voices combined) can pick a different "smoothest" chord pair than least largest leap (L∞, the single biggest jump). Affects this tab only, not the map's suggestion rings.
One honest gap
Your progression still plays and exports with the nearest-register voicing you actually hear, which can move more than this optimum — the line below the metrics shows by how much.
Voice labeling
Low-to-high: with 3–5 tones per chord (triads, sevenths, slash bass) there is no fixed four-part SATB texture.
Reading the roll
Line color follows an individual voice — the same color stays with a voice from chord to chord, including through a crossing, so you can trace one line by eye instead of guessing from slope. A held common tone is already obvious as a flat horizontal line, so it gets no separate treatment. Colors are a rendering aid only: this app has no persistent named-voice (S/A/T/B) data, so a color can start or drop out when a chord's note count changes. Smoothness = 100 × (1 − average motion ÷ 6), so 100 means every voice is held and 0 means voices average a tritone or more.

Cylinder map — the key as a space

Drag to orbit · wheel to zoom · click a chord to audition · double-click a path to focus

How to read this map

Radius = brightness
Dark chords sit near the center axis. Bright chords sit out at the rim.
Height = stability
Tense chords sit low. Stable chords sit high.
Angle around the rim = root
Roots run in chromatic order, so B sits next to C and the ring has no seam. Switch between the two orderings with the rim-order dropdown at the top of this tab.
Full colour = in key
The chord carries its degree's actual harmonic function.
Muted = right root, wrong quality (borrowed color)
The root belongs to the key, but the chord is played with a quality that isn't native to it, like a minor 7th chord on the tonic root.
Faded = borrowed or chromatic root
The chord is genuinely outside the key: a chromatic root, or a chord drawn from a parallel mode.

Selection

Click a chord or path segment to inspect it. Plain click selects and auditions. Progression chords audition with the exact voicing/inversion currently shown in Voice Leading.

Interaction

The 12 root labels stay visible around the rim. Click a segment to inspect its relationship and exact voice-leading distance. Double-click a path to focus the camera on that move. To insert or revise with this view, first start Insert or Revise from Build.

What this view is
A second view of the same field the Build map uses — here the seven diatonic chords of sit as a constellation, and your progression threads through them as a path you can orbit. Playing the progression sends a pulse along that path and the active chord briefly brightens and grows in place. Clicking a chord or path segment auditions and inspects it — it never changes the progression by itself. Adding or replacing a chord from this view only happens if Insert or Revise was already started on the Build tab; a banner above the stage shows when that's the case.
Honest caveat: coordinates
Brightness and stability are the same hand-placed coordinates as the 2D map — a legible approximation, not a rigorous metric — so read nearness as "roughly similar in character," not exact.
Honest caveat: dark-chord crowding
Because radius shrinks toward the centre, the darkest chords crowd together near the axis: two dark dots looking close there can be further apart in root than they appear.
On the rim toggle
Chromatic order puts semitone neighbours next to each other, so it's the honest map of voice-leading distance. Circle of fifths puts functional neighbours next to each other instead — a ii–V–I becomes a walk along the rim rather than a scatter across it — which is better for seeing cadential pull, not voice-leading smoothness. Neither layout is more correct; they answer different questions, and switching changes only which chords sit next to which, nothing else about the field.

Harmonic Rhythm Editor

Editing a block
Click a block to hear it and select it (for Blank bars, below). Drag its body to move it, or drag its right edge to change how long it holds. −/+ steppers do the same without dragging. Everything snaps to the note grid shown behind the blocks.
Markers & zoom
Dashed dividers are key/meter changes — click one to edit it. Drag "Timeline width" left to fit more on screen at once, right to zoom in for precision.
The grid is fixed
Its length is a setting (the "Grid length" control above), not something that grows or shrinks as a side effect of an edit — matching Logic's Step Sequencer length dropdown rather than an elastic timeline. "Auto" sizes it to whatever the progression currently needs, rounded up to a full bar; picking a bar count locks it there.
Every chord has a real position
Same as a note in a DAW piano roll: a chord is always sitting somewhere specific, never "following" a neighbor. Dragging a block moves only that block. With Ripple off, nothing else can ever move it. With Ripple on, changing a neighbor's note value can push or pull it (see Ripple below).
Ripple
One switch, shared with the Build tab. On (the default): making a chord longer pushes the chords in its way later, and making it shorter pulls the chords touching its end in. It stops at the first gap, so gaps you placed on purpose survive. Melody and bass notes that start inside a moved chord move with it. Off: exactly the older behavior below.
Shortening a chord
Ripple on: the chords touching its end slide left to close the space, stopping at the first gap. Ripple off: nothing else moves, a gap just opens up.
Lengthening a chord
Ripple on: chords in the way are pushed later, stopping at the first gap. On a locked grid length, a push that would run past the end is refused with a message, never trimmed. Ripple off: capped at the next chord's start, and the app tells you when that cap changed your pick.
What Ripple does not cover yet
Ripple applies to the note-value dropdown on Build and to the −/+, triplet and dotted buttons here. Dragging a block's right edge is not rippled yet: it still stops at the next chord. A long melody or bass note that starts before a pushed chord keeps its own start and length, so it can overlap the pushed chord differently than before.
Blank bars
Click a chord block to select it, then open Blank bars in the toolbar. Choose Before or After the selected chord, set how many bars, and Insert or Remove. Insert moves that chord and every chord after it later by whole bars of the meter in force there. Remove needs a full bar of time already empty in front of the chord, and it moves the whole tail earlier. Melody and bass notes at or after that chord move too, unless you untick "Move melody/bass too". Ripple does not matter here, and one press is one undo step.
Blank bars: the honest limits
A key or meter change hangs off the chord after it, so a blank bar inserted at a meter change takes the meter before the change, not the new one. If the chord you pick does not start on a bar line, the new space is one bar long but does not line up with the bar lines. A long note that starts before the insert point keeps its own start and length. On a locked grid length, an insert that would run past the end is refused.
Moving a chord
Dragging left closes any gap in front of the previous chord, then trims that chord's own duration to keep making room — down to a one-sixteenth-note floor, or a key/meter marker, whichever it hits first. Dragging right is capped the same way lengthening is — it stops at the next chord or the grid's end, never crosses it. It never reorders the harmony itself.
Bar lines
Placed using whichever time signature is active at that point in the progression. A meter change restarts bar counting from there.
Resolution
Whole, half, quarter, eighth, and sixteenth notes — that's also the finest grid increment blocks snap to. Triplets and dotted values aren't supported in the UI yet, though the grid's internal resolution was built so adding them later won't require rebuilding it.
Adding a meter change
Meter changes ride on the same markers as key changes — add one with "+ key change" on the Build tab, then set its meter here or in the marker editor. A marker doesn't have to change the key to carry a meter change.
Hearing it back
Silence and chord positions play back exactly as shown — but they aren't in the exported MIDI file yet. That fix is queued as its own careful pass since it touches the MIDI export engine directly.

What this is
A place to write an actual melody and bass line — notes with their own start, length, and pitch — separate from the single melody/bass note each chord can carry on the Build tab.
Placing notes
Click an empty spot in either lane to drop a note at that pitch and time. Drag a note to move it — it sounds again each time it crosses into a new pitch, so you can hear where it's landing. Drag its right edge to change its length. Right-click, long-press on touch, or select it and press Delete/Backspace/X to remove it.
Selecting several at once
Drag across empty space to lasso a group of notes — from either lane, or both at once. Shift-click toggles one note in or out of the selection. Grab any selected note to drag the whole group together; erase any one of them (or press Delete/Backspace/X) to erase the whole group.
Row height
The −/+ buttons in the melody/bass groups above zoom each lane's pitch rows independently — taller rows are easier to grab, at the cost of needing to scroll vertically to reach the rest of the 3-octave range. Horizontal zoom is shared with the Rhythm tab's own "Timeline width" control above.
Snapping
Notes snap to the same sixteenth-note grid as the Rhythm tab. That grid will get finer once triplets and dotted values ship there — these lines will follow along.
Bar lines and numbers
The amber lines mark where each bar starts, in both lanes. The numbers sit in the strip between the lanes and match the Rhythm tab's bar numbers, so bar 3 here is bar 3 there. A meter change restarts the bar length from that point but the numbering keeps counting.
Pitch is free
Nothing restricts which notes you can place — passing tones, chromatic motion, and leaps outside the chord are all allowed on purpose.
Tone coloring
Each note is checked against whichever chord is sounding at the moment it starts. Chord tones and other in-key notes look exactly like they always have. A note that's genuinely outside the key turns red — the same red used for the parallel-5th/8ve flag below — so red always means "worth a second look," nothing more. This is a read, not a rule — nothing is ever blocked.
Motion analysis
The summary bar above the lanes shows how the two lines move against each other — contrary, similar, oblique, or static — measured at every point where either line's note changes. This is only measured where both lines are actually sounding; a stretch where one line is resting is left out rather than guessed at, so a rest can visibly break up a run of contrary or similar motion in the percentages.
Parallel 5ths/8ves & voice crossing
Small dots above the lanes flag parallel perfect 5ths/octaves and moments where the melody dips below the bass. These are advisory, not errors — parallel motion is a real stylistic choice in a lot of electronic and pop writing, so nothing is blocked or auto-corrected. Hover a dot for the specific notes involved.
Not yet included
These lines don't factor into the Build tab's voice-leading analysis or MIDI export yet — they play back on their own synths, with their own playhead highlighting, for now.

Findings, not interpretation
Everything on this tab is a finding — something this app already computes about your progression (function, cadence, pitch content, tension position). There's no interpretive reading here yet; an Emotional Map layer is proposed for a later phase, not this one.
The timeline
Chord symbol and function read left to right in musical order; block width follows each chord's actual duration (compressed for legibility, not literal rhythmic notation). Key regions are labeled above the group of chords they cover.
Chord-color tension contour
The line beneath the timeline plots where each chord type sits on the app's own brightness/tension map — an intrinsic property of the quality itself (major 7, dominant 7, diminished, and so on). It does not measure the actual voicing, spacing, or register you're hearing in Voice Leading or Rhythm, and it is not an emotional reading of any kind.
Directional pull
Shown in words, never a number, in the detail panel below the timeline, and for the whole progression under Pull list: whether a chord carries a strong tonal or modal pull toward the local tonic, and whether the very next chord resolves it. This reuses the same cadence classification the Harmonic Arc export already uses, so the two always agree.
Selecting a chord or connector
Click or tap a chord to hear it and see its full findings below — the same audition glow lights up here and in Voice Leading. Click a connector between two chords to hear both in order and see that transition's findings. This view never edits your progression; use Build or Voice Leading to change anything.
Sections below the timeline
Summary, Key regions (when there are three or more), Harmonic arc, Pull list, Root motion, the voice-leading summary, the per-chord table and the terms are the same Analysis document the Export menu saves, built from one source, so this tab and the file always agree. They redraw as you edit while this tab is open. The tension contour and click to hear exist only on this tab.
